follow doc + must have oracle version in cluster
1. go to oracle container-registry:  https://container-registry.oracle.com
2. login / create account for the first time, need to verify email.
3. Homepage -> database -> enterprise-> select Language -> take license (green mark will show)
    [You last accepted the Oracle Standard Terms and Restrictions on 06/03/2026 at 06:09 AM Coordinated Universal Time (UTC).]

4. generate token -> copy it to a safer place
5. create secret: 
--docker-username="<your-oracle-account-email>"  = takia@appscode.com
--docker-password='<token-from-container-registry.oracle.com>' = secret that is copied from oracle
--docker-email="<your-oracle-account-email>" = takiaesha03@gmail.com

    
 kubectl create secret docker-registry oraclecred \
  --docker-server=container-registry.oracle.com \
  --docker-username="<your-oracle-account-email>" \   
  --docker-password='<token-from-container-registry.oracle.com>' \
  --docker-email="<your-oracle-account-email>" \
  --namespace=demo

6. deploy standalone-oracle , just mention imagePullSecret = oraclecred. take huge time to get ready 

7. exec into a pod and run commands: 
kubectl exec -it -n demo pods/oracle-0 -- bash 
Defaulted container "oracle" out of: oracle, oracle-init (init)
